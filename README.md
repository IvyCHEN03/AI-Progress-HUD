# AI-Progress-HUD

macOS AI Progress HUD

## Daily review and debugging routine

Use this lightweight checklist each day:

1. Launch the app and confirm it starts without errors.
2. Verify the HUD updates when progress changes.
3. Check logs/console output for warnings or failures.
4. Reproduce and fix any issue found that day.
5. Re-run the app and confirm the fix works.
6. Document what was reviewed, what was fixed, and any follow-up tasks.
